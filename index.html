Keeping your AI key safe

    

  • Think of it like a credit card number: if someone uses your key, you get charged.
    • 

  • Never put it in a chat, email, post, screenshot or file you send. Anyone with it can use your credit.
    • 

  • Make a key just for this page and give it a clear name. Then you can delete it without breaking anything else.
    • 

  • This page only saves your key if you tick Remember my key. If you don't, refreshing or closing the tab clears it.
    • 

  • Ticked it? Untick the box to delete the saved key, and never do it on a shared computer.
    • 

  • If your browser or password manager offers to save it, choose "Never" unless you really want that.
    • 

  • Use your own device. Avoid shared or public computers, and close the tab when you're done.
    • 

  • Only install browser add-ons you trust. Add-ons can read what's on a page.
    • 

  • Think a key got out? Don't wait. Delete it (Anthropic): log in to your Anthropic account, open the API keys page from your profile, tap the three dots by the key and choose Delete API Key. Then make a new one and check your usage.
    • 

  • Another AI company? Use the keys page in your account with them.
    • 

  • Swap your key for a new one now and then. Anthropic's guide suggests about every 90 days.
    • 

  • If a key ends up in a public GitHub repo, GitHub tells Anthropic and the key is switched off automatically. Don't count on that.
    • 

  • Read Anthropic's own guide: API key best practices. It has the current steps.
    • 



Real page or fake?

    

  • Anyone can copy a web page and change it to steal keys. Only paste your key on the real link: fishing-cat-data.pages.dev
    • 

  • Check the address bar before you paste. Bookmark the real link.
    • 

  • If the page is opened from a different address, it shows a red warning and locks the key box. Copies can remove that warning, so still check the address yourself.
    • 

  • Be careful with links sent by strangers, even if the page looks the same.
    • 

  • This page will never ask for your password, your email or anything except the AI key.

Privacy

    

  • Your AI key stays in this browser. It is only kept if you tick Remember my key, and it is never sent anywhere except the AI company you pick.
    • 

  • The page is locked down by the browser so it can only talk to Anthropic, Google and OpenAI. It only sends to the one you pick.
    • 

  • Your pictures (and the stills pulled from a video) go only to the AI company you pick, straight from your browser, to be read. This page has no server of its own, so we never see them.
    • 

  • What that company does with what you send is covered by its own policies. Free plans can have different rules, so check them.
    • 

  • Saved on your device only: theme, text size, and the last sheet you chose (names and points). Settings has a Privacy section that lists what is saved and can delete it, or stop saving the last sheet.
    • 

  • No accounts and no tracking added by this page. The page is hosted on a normal website host, which may keep normal visit records like any website host.
    • 

  • Bills: the whole photo goes to the AI company, including your name, address and account number. The page asks the AI not to copy those, and the sheet has no place for them.
    • 

  • The names in your pictures belong to real people. Share the sheet only with people who should see it.
